# Gemelo Digital – Sistema Bioelectroquímico de 3 Cámaras

Simulador interactivo de un sistema bioelectroquímico automatizado a escala 1 litro para recuperación de metales y biorremediación de efluentes de baterías ion-litio con *Pseudomonas putida*.

## Stack
- Python · Streamlit · NumPy · SciPy · Plotly

## Correr localmente

```bash
pip install -r requirements.txt
streamlit run app_simulador_3camaras.py
```
